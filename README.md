# Face Recognition Attendance System

Face Recognition Attendance System developed using **Python** and **OpenCV**. This project uses facial recognition technology to identify registered users and automatically mark their attendance, reducing the need for manual attendance.

## Features

* Real-time face detection and recognition
* Automatic attendance marking
* Easy to use
* Fast and accurate attendance recording

## Technologies Used

* Python
* OpenCV
* face_recognition
* NumPy
* Pandas

## How to Run

1. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the project:

   ```bash
   python run_all.py
   ```

## Requirements

* Python 3.x
* Webcam
* Required Python libraries
